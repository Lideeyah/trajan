# Security model

Trajan is seller tooling over the Machine Payments Protocol. This note says what it holds, what it never holds, and what is and isn't verified. It is not an audit.

## What Trajan never holds

- **Buyers' funds.** Payment is a TIP-20 transfer from the agent to the seller's address, verified by `mppx`. Trajan is not in the path of the money.
- **Sellers' funds.** Payments settle directly at the seller's Tempo address. The console reads balances; it doesn't custody anything.
- **Sellers' keys, on Trajan Cloud.** A hosted account is a passkey (WebAuthn, bound to `trajan-five.vercel.app`). The P256 key lives in the seller's device; the server stores the public key and credential id only. Cloud cannot sign on a seller's behalf, which is why hosted Cash out does not send yet.

## What a seller's own server holds (self-hosted)

- `MPP_SECRET_KEY` — `mppx`'s challenge-signing secret. Generated by `trajan init`, kept in `.env`.
- `TRAJAN_WITHDRAW_KEY` (optional) — the recipient's private key, only if the seller wants the console's Send form. Treat it like any production secret; omit it and send from your wallet instead.
- `TRAJAN_FEE_PAYER_KEY` (optional) — a funded key that sponsors buyers' fees. It can only be drained by fees on transactions the server co-signs; `mppx` caps in-flight exposure (`sponsorBudget`).
- `TRAJAN_API_KEY` (cloud) — lets the server report calls to the hosted console. Stored hashed (SHA-256) on the server side; shown once; rotatable from the console.

## Trajan Cloud

- Sessions are `httpOnly`, `SameSite=Lax` cookies issued by Tempo Accounts' WebAuthn handler; challenges and sessions live in Postgres with atomic create/take.
- `/ingest` is authenticated by API key and idempotent per `(seller, challenge_id)`. Rows are append-only from the seller's perspective.
- Every console route is scoped to the signed-in seller's rows. There is no admin view.
- Secrets (database URL) are Vercel environment variables, not in the repo.

## What is not verified

- No third-party audit of Trajan's code. The payment path is upstream `mppx`; Trajan's own code is the CLI, the call log, the console and the ingest API.
- Testnet only (Tempo Moderato). Mainnet is a configuration flag, not a tested deployment.
- The hosted service is a single Vercel project with a single Neon database; there is no rate limiting on `/ingest` beyond Vercel's defaults.
